A tiny deterministic program that writes exactly one original joke — a single funny line that lands on a cold read — to `/output/entry.txt`. No setup notes, no explanation, just the punchline. Built for make.fun's "One-Line Laugh-Off" bounty, where a judge model reads entries head to head and the funniest line takes the whole reward.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes the joke to `/output/entry.txt` (creating `/output` if needed).
